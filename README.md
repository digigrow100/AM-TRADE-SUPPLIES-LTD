# AM TRADE SUPPLIES LTD website

Next.js (App Router), TypeScript and Tailwind CSS.

- `npm run dev` – local development
- `npm run build && npm start` – production build

Business details live in `src/config/site.ts`; product categories in `src/config/categories.ts`; navigation in `src/config/navigation.ts`.
Set `NEXT_PUBLIC_SITE_URL` once the domain is confirmed to enable canonical URLs, the sitemap and structured-data URLs.
